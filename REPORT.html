💡 Tokenomics Metrics Summary & Quick Guide
Expand Guide ▾
Completion Token Output
Text generated by the model (code, answers). Typically 3x–5x more expensive per token than input tokens due to autoregressive decoding GPU compute.
Prompt Token Input
Text sent to the model (user prompt, codebase files, instructions). Significantly cheaper per token; further discounted by prompt caching.
Avg Tokens / $ Efficiency
Total Tokens / Total Spend ($). Measures cost-efficiency. Higher values mean more tokens processed per dollar spent (Higher is better). Includes Min-Median-Max range.
Completion Ratio Ratio
(Completion Tokens / Total Tokens) * 100. Shows whether a run is context-heavy (<5% reading code) vs generation-heavy (>15% writing code).
Tokens / Sec Speed
Total Tokens / Duration (s). Overall throughput speed measuring how fast the model and proxy ingest context and generate output (Higher is better).
Avg Duration Latency
Average total wall-clock elapsed time (in seconds) required for an agent to finish a benchmark task (Lower is better). Includes Min-Median-Max range.
